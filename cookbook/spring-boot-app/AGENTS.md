# AGENTS.md

## Stack
- Backend: Java 21 / Spring Boot 4.x (Maven)

## Commands
- Build: `./mvnw package`
- Test: `./mvnw test`
- Lint + verify: `./mvnw verify`

## Skills
Before writing code, load the relevant skill from `.github/skills/`:
- `java-patterns` — Java and Spring Boot coding standards
- `api-conventions` — REST API design standards

## Boundaries
- Do not edit generated files in `target/`
- Do not add dependencies without updating `pom.xml`
